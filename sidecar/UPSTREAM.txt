派生作品的变更声明（Apache-2.0 第 4(b) 条）
------------------------------------------
sidecar/laya_server.py 是实现 P0 接入（内容分类打分、会话意图短路）时，以
上游 java/backend/server.py 为基础改写而来，已按许可证第 4(b) 条在文件头标注
「派生自 …，已被修改」。相对上游的实际改动：

  a. 删除上游的测试台 UI（`GET /`）与 `/api/*` 端点，只保留 /health、/v1/predict、
     /v1/preload 三个 Java 契约端点；
  b. `POST /v1/predict` 的 `model` 缺省由 english 改为自动路由；
  c. 新增请求体上限 MAX_BODY_BYTES（2 MB）；
  d. HTTP 端口缺省由 8770 改为 8777，避免与上游 server.py 同时运行时冲突。

注意：sidecar/laya/*.py 未改一行，故不触发第 4(b) 条的修改声明义务；上游包内
无版权头、仓库根无 NOTICE 文件，故第 4(c)/4(d) 条无需额外保留或传递的内容。

本项目的 Java / 前端代码为原创实现（自写薄客户端 LayaDecisionClient 等），未拷贝
上游 java/ 目录下的源码或文档；docs/ 与 .trae/documents/ 下的集成文档亦为自行撰写。
